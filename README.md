# Кадры техники упражнений FitTracker

Отдельный репозиторий под бинарники: в проекте приложения (`fittracker-rn`) картинок нет,
там только код и скрипты. Приложение читает адрес кадра из колонки `exercises.media_url`
и скачивает его отсюда, поэтому замена картинки не требует пересборки приложения.

Репозиторий обязан оставаться **публичным**: адреса отдаёт `raw.githubusercontent.com`
без авторизации, приватный репозиторий даст 404 во всех карточках.

## Схема имён

```
exercises/<Имя_Упражнения_С_Подчёркиваниями>/
  00f.jpg  01f.jpg   — женская фигура: старт и финал
  00m.jpg  01m.jpg   — мужская фигура: старт и финал
  0.jpg    1.jpg     — легаси-схема зеркала free-exercise-db
```

- Размер кадра — 850×567 (3:2), JPEG, качество 88, вес 40–60 КБ. Другое соотношение
  сторон ломает расчёт бокса картинки в приложении (`mediaFit.ts`).
- `01f`/`01m` — вторая рамка той же пары: приложение достраивает имя само, из префикса.
- Перевод позиции на гендерную схему делается только когда в папке лежат **обе** пары,
  иначе профиль «мужчина» упрётся в 404.

## Как выпустить обновлённый кадр

1. Положить файл в нужную папку сюда, коммит, пуш в `main`.
2. В проде поднять номер версии в адресе: `…/00f.jpg` → `…/00f.jpg?v=2`
   (одна `UPDATE` строки `exercises.media_url`).

Номер версии обязателен: телефон ключует свой кэш по полному адресу, и без смены адреса
он продолжает показывать старые байты. Хост на хвост согласен — отдаёт те же файлы и
ключует свой край по полному адресу.

## Откуда что берётся

- 56 позиций на этом хосте (~10 МБ) — нарисованные нами кадры.
- Остальное — зеркало датасета [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (764 позиции, ~82 МБ). Приложение ходит по их адресам, а зеркало нужно для сверки
  целостности и на случай, если позицию переводят на наш хост.

## Проверка перед миграцией

Из проекта приложения:

```
python spark-output/export/check-media-names.py --http    # имя ↔ папка ↔ media_url ↔ HTTP
python spark-output/export/check-upstream-mirror.py       # зеркало совпадает с upstream
```

Путь к этому репозиторию скрипты ищут по соседней папке (`../fittracker-exercise-media`)
или по переменной окружения `FT_MEDIA_ROOT`.
